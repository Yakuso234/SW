## 项目经历

### SW 智能短视频微服务平台｜核心重构与后端开发｜个人项目

`Java 21 · Spring Boot 3 · Spring Cloud Alibaba · MySQL · Redis · RabbitMQ · MinIO · Milvus · FFmpeg · Spring AI · Vue 3`

基于经原作者许可的开源项目进行重构扩展，围绕“上传—异步处理—内容分发—互动运营—轻量变现”构建短视频业务闭环，并将原综合业务骨架收敛为聚焦视频主线的微服务平台。

- 设计“MinIO 预签名直传 → 本地事务 Outbox → RabbitMQ → FFmpeg 转码/抽帧 → 状态回写”异步发布链路，拆分视频、处理任务和消息投递状态，避免大文件经过业务服务并解决数据库与 MQ 双写空窗。
- 针对重复投递和处理回写失败，引入条件状态迁移、消费幂等、处理租约和 Outbox 扫描补偿；关注流采用 TTL 延迟重试、DLQ 与审计式恢复，保证异常任务可追踪、可恢复。
- 实现公开/关注双 Feed、视频与创作者搜索、点赞、收藏、评论、关注关系和创作者运营数据；Feed 使用游标分页，播放量通过 `(video_id, viewer_id, viewed_date)` 唯一约束实现登录用户每日去重。
- 在 Video 域实现视频挂商品、Redis Lua 秒杀、优惠券、订单履约与售后，以 MySQL 唯一约束兜底一人一单；12 个隔离买家争抢 3 件库存时成功 3、拒绝 9，MySQL 与 Redis 库存一致且无超卖。
- 构建 Spring AI + Qwen SSE 创作助手，由 Gateway JWT 和 ToolContext 绑定创作者身份；采用 Redis 最近会话、MySQL 可管理偏好与 Milvus 用户隔离索引实现低成本个性化，事实查询绕过偏好召回。
- 建立成功发布、无效媒体失败、租约恢复、关注流死信恢复、真实播放互动 E2E；固定本机串行场景下，2 秒视频从预签名请求到 `PUBLISHED` 的 5 次回归 P50/P95 为 3.50/3.51 秒。
